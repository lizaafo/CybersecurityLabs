# Lab 2 — Anomaly Detection

Comparison of Isolation Forest and an autoencoder with categorical embeddings on synthetic account-login events.

The completed notebook, including code, outputs, visualizations, and conclusions, is available in [AnomalyDetectionComparison.ipynb](AnomalyDetectionComparison.ipynb).

## How to run

1. Open [the notebook in Google Colab](https://colab.research.google.com/github/lizaafo/CybersecurityLabs/blob/main/labs/lab2/AnomalyDetectionComparison.ipynb).
2. Start a fresh session and run all cells from top to bottom.

The synthetic dataset is generated directly in the notebook.
The autoencoder setup cell installs Keras and PyTorch when needed
and configures the PyTorch backend.

Saved outputs include evaluation metrics, visualizations,
model comparisons, and analyst decisions for selected alerts.
